# Control Flow — Level 1

Covers basic conditionals (`if`, `if-else`) and loops (`while`, `for`) applied to fundamental logic problems.

## Exercises

| File | Problem Statement |
|---|---|
| CheckDivisibilityBy5.cs | Check if a number is divisible by 5 |
| SmallestOf3Numbers.cs | Check if the first of three numbers is the smallest |
| LargestOf3Numbers.cs | Check which of three numbers is the largest |
| NaturalNumberSum.cs | Check for a natural number and compute the sum of n natural numbers |
| VotingEligibility.cs | Check whether a person is eligible to vote based on age |
| NumberSignChecker.cs | Check whether a number is positive, negative, or zero |
| SpringSeason.cs | Check whether a given month and day fall within spring season |
| RocketCountdownWhile.cs | Count down from a user-input value using a while loop |
| RocketCountdownFor.cs | Count down from a user-input value using a for loop |
| SumUntilZero.cs | Sum numbers entered by the user until 0 is entered |
| SumUntilZeroOrNegative.cs | Sum numbers until the user enters 0 or a negative number, using break |
| NaturalNumberSumWhile.cs | Compute the sum of n natural numbers using a while loop and compare with the formula |
| NaturalNumberSumFor.cs | Compute the sum of n natural numbers using a for loop and compare with the formula |
| FactorialWhile.cs | Compute the factorial of a number using a while loop |
| FactorialFor.cs | Compute the factorial of a number using a for loop |
| OddEvenNumbers.cs | Print odd and even numbers up to a user-input value |
| EmployeeBonus.cs | Calculate employee bonus based on years of service |
| MultiplicationTable.cs | Print the multiplication table of a number for a given range |
