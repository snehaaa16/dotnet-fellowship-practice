# Control Flow

## Concept Overview

Control flow determines the order in which statements in a program execute. By default, a program runs top to bottom, but control flow constructs allow that order to change based on conditions or repetition. There are three categories:

1. **Selection** — chooses between alternative paths based on a condition. Constructs: `if`, `if-else`, `else if`, `switch-case`, ternary operator (`?:`).
2. **Iteration** — repeats a block of code while a condition holds. Constructs: `for`, `while`, `do-while`, `foreach`.
3. **Jump statements** — alter execution flow directly. Constructs: `break` (exits a loop), `continue` (skips to the next iteration), `return` (exits a method).
